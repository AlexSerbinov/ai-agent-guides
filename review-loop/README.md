# Review Loop

Ітеративне мультиагентне код-рев'ю для Claude Code. Запускає 6 паралельних агентів (4 Claude + 1 Codex + 1 Gemini), агрегує знахідки, авто-фіксить безпечні проблеми та повторює цикл поки якість коду не досягне >= 95%.

## Як працює

1. Ви запускаєте `/review-loop` в Claude Code
2. Паралельно стартують 6 рев'ю-агентів з різним фокусом (баги, безпека, breaking changes, архітектура)
3. Результати агрегуються, дедуплікуються та оцінюються (скор 0-100)
4. Безпечні проблеми (Critical/High/Medium) фіксяться автоматично
5. Цикл повторюється на виправленому коді - до 5 ітерацій або поки скор >= 95%

Ніколи не комітить - тільки рев'юїть та фіксить. Ви вирішуєте коли комітити.

## Як поставити собі

```bash
mkdir -p ~/.claude/skills/review-loop
```

Скопіюйте вміст [prompt-ukr.md](./prompt-ukr.md) в `~/.claude/skills/review-loop/SKILL.md` та перезапустіть Claude Code.

Або просто попросіть свого агента: "Встанови собі цей скіл" та дайте йому посилання на промпт.
