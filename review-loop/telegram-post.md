Поділюсь з вами своїм скілом на код рев'ю. Він значно спрощує мені життя і убезпечує від неочевидних багів. Бізнес-логіку не фіксить, але дуже добре рятує від race conditions, null dereference та іншої неочевидної фігні.

Зазвичай я запускаю його перед тим як щось комітити.

**Як працює:**
В мене є команда в Claude Code - `/review-loop`

Під капотом паралельно запускаються 4 саб-агенти Claude Code, 1 агент Codex і 1 агент Gemini CLI. Разом 6 рев'юерів одночасно.

Далі результат всіх 6 агентів агрегується головним агентом і робляться виправлення. Після виправлень знову запускаються ці самі 6 агентів, щоб перевірити що фікси не поламали щось нове. Якщо є проблеми - знову фікс, знову рев'ю. І так до 5 циклів, або поки review score не буде >= 95%.

До того ж рев'ю агенти працюють так, що якщо є критична проблема, то вони в результаті скажуть більше про критичні трабли і з меншою вірогідністю про менші проблеми. Запускаючи повторно, ви знайдете ВСІ проблеми :)

Весь цикл працює хвилин до 20, але воно того варте.

**Примітка:** будь-який сучасний AI-агент можна запускати в headless режимі. Тобто Claude Code може під капотом викликати Codex, або Codex - Gemini і т.д.

```
claude -p "зроби код ревью незакомічених змін"
```
```
codex --approval-mode full-auto -q "Review this code for bugs and security issues"
```

**Важливо:** бізнес-логіку він не фіксить. Додайте собі 7-го агента (тобто себе), який зверху перегляне зміни. І бажано запустіть сервіси і базово перевірте чи не поламалось нічого.
