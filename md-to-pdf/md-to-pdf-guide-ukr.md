# Markdown to PDF: конвертація документів для Claude Code

## Що це і навіщо?

Ви пишете документацію, гайди, звіти в Markdown - але іноді потрібен PDF. Для відправки клієнту, для друку, для шерінгу з людьми які не знають що таке markdown.

**Markdown to PDF** - це скіл (slash command) для Claude Code який конвертує `.md` файли у високоякісні PDF одною командою:

```
/md-to-pdf docs/my-report.md
```

Під капотом працює Puppeteer (headless Chrome) - тобто PDF виглядає рівно так, як markdown рендериться в браузері. Таблиці, код з підсвіткою, заголовки - все на місці.

### Що ви отримуєте:

- **Швидка конвертація** - 2-3 секунди, Chrome запускається тільки на час конвертації і закривається
- **Автоматичне відкриття** - PDF одразу відкривається після генерації
- **Розумні edge cases** - директорії, raw текст, кастомний output path
- **Верифікація layout** - опціональна перевірка що сторінки виглядають нормально
- **CSS контроль** - page-break правила для таблиць, код-блоків, заголовків

### Чого це НЕ робить:

- Не конвертує інші формати (тільки .md -> .pdf)
- Не має GUI - працює тільки через Claude Code CLI
- Не підтримує кастомні шрифти або теми (використовує стандартний стиль Chrome)

## Передумови

### 1. Claude Code

Встановіть якщо ще не маєте: https://claude.ai/code

### 2. md2pdf CLI

Це Node.js пакет який використовує Puppeteer для конвертації.

**Встановлення через npm:**
```bash
npm install -g md-to-pdf
```

Після встановлення команда `md2pdf` (або `md-to-pdf`) має бути доступна в терміналі.

### 3. pdftoppm (опціонально)

Потрібен тільки для верифікації layout (конвертація PDF сторінок в PNG для візуальної перевірки).

```bash
# macOS
brew install poppler

# Ubuntu/Debian
sudo apt-get install poppler-utils
```

## Встановлення скілу

### Автоматичне (через агента)

Скопіюйте наступний текст і дайте своєму AI-агенту:

`Перейди за посиланням https://github.com/AlexSerbinov/ai-agent-guides/blob/main/md-to-pdf/prompt-ukr.md, прочитай текст цього скілу і встанови його мені як скіл на комп'ютер.`

Агент прочитає промпт, створить файл `~/.claude/commands/md-to-pdf.md` і скіл буде доступний як `/md-to-pdf`.

### Ручне

1. Створіть директорію (якщо не існує):
```bash
mkdir -p ~/.claude/commands
```

2. Скопіюйте вміст [prompt-ukr.md](./prompt-ukr.md) у файл:
```bash
~/.claude/commands/md-to-pdf.md
```

3. Перезапустіть Claude Code.

4. Перевірте що скіл з'явився:
```
/md-to-pdf --help
```

## Як це працює

### Базове використання

```
/md-to-pdf docs/report.md
```

Це конвертує `docs/report.md` у `docs/report.pdf` і відкриє PDF.

### З кастомним output шляхом

```
/md-to-pdf docs/report.md output/final-report.pdf
```

### Edge cases

| Ситуація | Поведінка |
|----------|-----------|
| Дали директорію | Шукає README.md або єдиний .md файл всередині |
| Дали raw текст | Зберігає у тимчасовий .md файл, конвертує, повідомляє шлях |
| Файл не існує | Показує помилку |
| Без output шляху | PDF зберігається поруч з .md файлом |

### Верифікація layout (опціонально)

Якщо попросите Claude перевірити layout, він:

1. Конвертує PDF сторінки в PNG через `pdftoppm`
2. Переглядає кожну сторінку візуально
3. Шукає проблеми:
   - **Orphaned heading** - заголовок внизу сторінки, текст на наступній
   - **Split table/code block** - таблиця або код розірвані між сторінками
   - **Empty/sparse page** - сторінка з менше ніж 30% контенту
4. Фіксить через CSS page-break правила
5. Перегенерує PDF

### CSS для контролю page-breaks

Додайте на початок .md файлу для кращого layout:

```html
<style>
table { page-break-inside: avoid; margin-bottom: 1em; }
pre { page-break-inside: avoid; }
blockquote { page-break-inside: avoid; }
h2, h3, h4 { page-break-after: avoid; orphans: 3; widows: 3; }
p { orphans: 3; widows: 3; }
li { page-break-inside: avoid; }
</style>
```

Для примусового розриву сторінки перед великими секціями:

```html
<div style="page-break-before: always;"></div>
```

## FAQ

**Q: Chrome залишається запущеним після конвертації?**
A: Ні. Chrome запускається тільки на час конвертації (2-3 секунди) і автоматично закривається.

**Q: Чи працює з великими файлами?**
A: Так, але для дуже великих документів (100+ сторінок) конвертація може зайняти довше. Timeout встановлений на 30 секунд.

**Q: Чи підтримує mermaid діаграми?**
A: Залежить від конфігурації md2pdf. За замовчуванням - ні, потрібен додатковий плагін.

**Q: Чи можна конвертувати кілька файлів одночасно?**
A: Скіл приймає один файл за раз. Для batch конвертації попросіть Claude зробити це в циклі.
