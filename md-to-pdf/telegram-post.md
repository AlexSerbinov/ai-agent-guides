Минулого тижня робив документ на оцінку проекту, і стало завдання згенерувати його в класному, гарному вигляді. Для цього створив окремий скіл - Markdown to PDF.

**Що робить цей скіл?**
По суті, ви можете створювати будь-які красиві PDF-документи. Як це працює: ви відкриваєте Claude Code (чи Cursor, чи будь-який агент який вміє працювати з Markdown), просите написати або відредагувати документ в Markdown-файлі. Потім просто кажете `/md-to-pdf` - і через 2-3 секунди отримуєте готовий PDF.

```
/md-to-pdf docs/project-estimate.md
```

(Якщо хтось ще не користується Markdown - раджу переходити на нього замість DOCX або Google Docs. LLM-и дуже добре з ним працюють, і це просто текстовий файл який можна тримати в git.)

**Як воно працює під капотом:**
Скіл запускає headless Chrome (Puppeteer), рендерить markdown і віддає PDF. Chrome запускається тільки на час конвертації (~2-3 секунди) і закривається. Після цього PDF автоматично відкривається.

**Розумні edge cases:**
- Даєте директорію замість файлу - шукає README.md всередині
- Даєте просто текст (без .md файлу) - зберігає у тимчасовий файл і конвертує
- Можна вказати output шлях: `/md-to-pdf report.md output/report.pdf`

Ще є опціональна верифікація layout - якщо попросите, скіл перевірить що в PDF немає orphaned headings, розірваних таблиць чи порожніх сторінок. Якщо знайде - пофіксить і перегенерує.

**Як поставити собі:**
Скопіюйте наступний текст і дайте своєму агенту (Claude Code, Codex, Cursor - будь-якому):

`Перейди за посиланням https://github.com/AlexSerbinov/ai-agent-guides/blob/main/md-to-pdf/prompt-ukr.md, прочитай текст цього скілу і встанови його мені як скіл на комп'ютер.`

Або [почитайте детальніше](https://github.com/AlexSerbinov/ai-agent-guides/blob/main/md-to-pdf/md-to-pdf-guide-ukr.md) як це працює і поставте вручну.

**Передумова:** потрібен пакет `md2pdf` (`npm install -g md-to-pdf`). Агент встановить автоматично якщо не знайде.
